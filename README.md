# FrameDrop — TikTok-Ready Frame Rate Converter

100% client-side video converter (frame rate / resolution / quality) built with React (CDN) + Tailwind (CDN) + FFmpeg.wasm (single-threaded, 0.11.6). No backend, no build step — a single `index.html` file.

## Deploy on Vercel
This is a static site — no framework, no build command needed.

1. Push this repo to GitHub (see below).
2. Go to https://vercel.com/new and import the repo.
3. Framework Preset: **Other**
4. Build Command: *(leave empty)*
5. Output Directory: *(leave empty / `.`)*
6. Click **Deploy**.

That's it — `index.html` is served as-is.
